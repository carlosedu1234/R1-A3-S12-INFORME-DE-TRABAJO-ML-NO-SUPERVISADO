# Segmentación de inmuebles en arriendo usando algoritmos no supervisados

## Descripción

Esta actividad busca identificar grupos de inmuebles en arriendo con características similares, teniendo en cuenta variables como el precio, el área, el número de habitaciones, los baños y la ubicación.

Para ello, se utilizan dos técnicas de aprendizaje no supervisado: **K-Means**, para agrupar las propiedades, y **PCA**, para reducir la dimensionalidad de los datos y visualizar los resultados.

## Objetivos

- Identificar segmentos de inmuebles mediante K-Means.
- Comparar los resultados utilizando 2, 3 y 4 clusters.
- Aplicar PCA para analizar la varianza explicada y visualizar los grupos.
- Proponer estrategias comerciales según las características de cada segmento.

## Herramientas utilizadas

- Python
- Pandas y NumPy
- Scikit-learn
- Matplotlib y Seaborn
- Excel

## Metodología

Se realiza el preprocesamiento de los datos, el escalamiento de las variables y la aplicación de K-Means para identificar grupos de propiedades similares. Posteriormente, se utiliza PCA para reducir las dimensiones, visualizar los clusters y analizar los resultados obtenidos.

## Conclusión

Esta actividad permite explorar cómo el aprendizaje no supervisado puede ayudar a comprender mejor el mercado inmobiliario, identificar segmentos de propiedades y plantear estrategias comerciales que faciliten la búsqueda de inmuebles y mejoren las recomendaciones para los clientes.
